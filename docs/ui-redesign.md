# UI 视觉优化说明

> 日期：2026-11-05
> 范围：Web 管理端全部页面与三维工厂；仅调整样式、布局与交互呈现，不改接口、表结构与业务逻辑。

---

## 1. 设计定位

工业互联网 / 能源数字化 / 智慧工厂 / 专业能源管理平台。

- **业务页**：浅灰背景、白色卡片、深色文字、统一蓝色主色，弱阴影、细边框，信息密度适中。
- **驾驶舱 / 三维工厂**：深蓝底色，克制的网格与面板，不使用大面积渐变、发光、玻璃拟态。
- **数字与标签**：数字统一等宽（tabular-nums），风险/状态统一标签与色点体系。

---

## 2. 设计令牌

`web/src/styles/index.css` 定义全局变量与 Element Plus 覆盖：

| 类别 | 令牌 |
| --- | --- |
| 主色 | `#1d4ed8`，悬停 `#1e40af`，浅底 `#eff4ff` |
| 背景 | 页面 `#f5f7fa`，卡片 `#ffffff`，弱底 `#f8fafc` |
| 文字 | 主 `#0f172a`、次 `#475569`、弱 `#94a3b8` |
| 边框 | `#e3e8ef`，强 `#cbd5e1` |
| 语义 | 成功 `#16a34a`、警告 `#d97706`、危险 `#dc2626`、信息 `#2563eb` |
| 形状 | 卡片圆角 14px、控件 6px、标签 5px；阴影仅 1px 层级 |
| 字号 | 正文 14px、辅助 12–13px、页面标题 20px、KPI 26px |

同时统一了卡片、表格（表头浅灰、行悬浮、单元格不换行）、筛选器、分页、弹窗、抽屉、表单、空态、加载遮罩与滚动条。

---

## 3. 布局与导航

- 左侧导航：232px 深蓝侧栏，Logo 增加副标题「工业能耗管理平台」，菜单项圆角 + 当前项左侧 3px 蓝色标记，底部数据服务状态；窄屏自动折叠为 64px。
- 顶部导航：58px 白色栏，首页图标 + 面包屑，右侧头像/角色/企业信息下拉。
- 内容区：统一 18–20px 内边距；页面级 `.page-header`（标题 + 说明 + 操作）用于异常、基线、设备、企业、车间、产线、用户、角色等页面。
- 工作台：问候区 + 服务状态 + 8 个常用功能入口（按权限展示）+ 数据口径说明，移除过期的阶段说明文案。

## 4. 图表统一

新增 `web/src/utils/chartTheme.ts`，`BaseChart` 自动套用：

- 统一字体（Inter / PingFang SC）、8 色工业蓝绿橙红配色。
- 坐标轴：轴线 #e2e8f0、虚线网格、11px 轴标签。
- 提示框：白底细边框、12px 字号、虚线轴指示器。
- 图例：圆角小方块，右上角对齐。
- 深色模式：深蓝面板、浅色文字、低对比网格。
- 基线/实际/节能量固定语义色：基线橙色、实际蓝色、节能绿色、异常红色（`PALETTE`）。

空数据统一显示空态而非空白画布；加载文案修复为「加载中…」。

## 5. 业务视觉

| 对象 | 规则 |
| --- | --- |
| 风险 | 正常绿、低黄、中橙、高红、离线灰；3D 设备地面环与指示灯同色 |
| 设备状态 | 运行绿、停机灰、检修黄、离线灰（标签） |
| 任务状态 | 待分配灰、待整改黄、整改中蓝、待审核橙、效果验证蓝、完成绿、驳回红、撤销灰 |
| 诊断状态 | 待确认橙、已确认蓝、已忽略灰 |
| 核算结论 | 达成绿、无变化灰、恶化红、数据不足/不可比黄、停机灰 |

标签统一 22px 高、5px 圆角、浅底细边框；表格内状态列宽已按最长标签调整。

## 6. 三维工厂

- 风险色重新校准（正常 `#22c55e`、低 `#eab308`、中 `#f97316`、高 `#ef4444`、离线 `#64748b`），降低自发光强度，仅高风险保留缓慢脉冲。
- 设备增加基座与地面风险环，强化「厂房 → 产线 → 设备」层次；产线增加名称标签。
- 移除整体缩放脉冲，避免设备抖动；保留风机旋转作为运行状态提示。
- 相机取景收紧（按场景尺寸 0.44 倍半径），厂房与设备更清晰。
- HUD 保留车间/产线/设备/今日能耗统计与风险图例；设备/产线详情中的过期「P5/P6 待接入」文案已改为「暂无基线/暂无异常」。

## 7. 体验

- 表格：表头统一、行悬浮、单元格省略与 tooltip（任务号/标题）；操作列宽度按按钮数量调整，避免换行遮挡。
- 分页统一右对齐并保留总数/页大小。
- 空态、错误提示、重试按钮沿用页面既有逻辑，样式统一。
- 登录页：左侧深蓝品牌区（细网格，无大面积渐变）+ 右侧表单卡，演示账号可点击自动填充；移动端隐藏品牌区。
- 响应式：1100px 以下侧栏自动折叠，768px 以下 KPI 两列、筛选器换行。

## 10. 剩余问题

1. 部分详情页仍保留早期内联颜色（如驾驶舱图表中的个别十六进制色），已由统一主题兜底，但未逐行替换为令牌。
2. 数据湖、画像等页面以全局样式覆盖为主，未逐页增加标题区；与新增标题的页面在层级上略有差异。
3. 驾驶舱 4 个 KPI（偏差率/异常设备/整改任务/节能量）后端仍返回 `available=false`，界面显示「— / 当前范围暂无数据」；需后续在画像聚合中接入真实值。
4. 三维工厂默认展示首个企业场景（4 台设备），联调企业 30 台设备需通过后端场景选择扩展后才能展示更大规模。
5. 小程序端未做本轮视觉调整，保持原有原生样式。
